## Struktur File
* `index.html` - Halaman dashboard utama
* `login.html` - Halaman masuk pengguna
* `mahasiswa.html` - Menampilkan tabel data mahasiswa
* `jadwal.html` - Menampilkan tabel jadwal perkuliahan
* `css/style.css` - File styling untuk seluruh halaman

## Cara Menjalankan
1. Lakukan *clone repository* ini: `git clone https://github.com/rivaldiwahyu02/aplikasi-akademik-kelompok.git`
2. Buka folder proyek.
3. Klik ganda pada file `login.html` atau `index.html` untuk menjalankannya di browser lokal Anda.
